- `home.jpg` — role-aware landing page after login
- `dashboard.jpg` — KPI cards and risk ranking after the loading animation completes
- `devices.jpg` — device inventory table
- `failures.jpg` — failure list and summary
- `maintenance.jpg` — maintenance records and related controls
- `logs.jpg` — MongoDB-backed logs view
- `analytics.jpg` — OLAP charts and rollup tables
